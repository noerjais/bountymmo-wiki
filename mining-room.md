# Mining Room

To enter into mining room you must pay 88k zeny. This room is **NOT** time expire and until you are online (and alive), you can stay here and farm stuffs. Into mining room exist 3 type of Crystals, they have a life of 50 hp but the max damage is only 1. So basically you must attack them 50 times to kill.
There are also skeleton workers with HUUUGE life that apply dispel and stone cursed to you, so the advice is avoid them! It's useless try to kill them.

The difference between the Crystals is the % of drops from each item, without using any drop rate gears nor VIP perks the % drops is explained into table below:

| | Name | % drop | ID |
| --- | --- | --- | --- |
| | Crystal I | 15 | 3912 |
| | Crystal II | 25 | 3913 |
| | Crystal III | 50 | 3914 |
