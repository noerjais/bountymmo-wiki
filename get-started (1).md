# get started

After downloading and launching the client (remember to patch it!), follow these instructions if you are new to a Ragnarok Private Server:

{% stepper %}
{% step %}
## Accept the Terms and Conditions

You must accept Terms and Conditions.
{% endstep %}

{% step %}
## Choose a server

**Choose the server that is closest to you.**
{% endstep %}

{% step %}
## Log in

Insert the same credentials used on the site where you created the account.
{% endstep %}

{% step %}
## Set your security PIN

Set and use a 4-number PIN every time you log in.
{% endstep %}

{% step %}
## Create a character

Create a character as you wish by clicking on the box with a cross and the word **NAME**.

Classes are chosen later, and you can also change your style later by talking with an NPC in major cities.
{% endstep %}

{% step %}
## Start the game

After choosing everything, press **Game Start**.
{% endstep %}

{% step %}
## Talk to the Freebies NPC

Once in the game, talk with the [Freebies NPC](<freebies-npc (1).md>), who gives you some items to start this adventure and helps you level your character.
{% endstep %}
{% endstepper %}
