# mining room

To enter the mining room, you must pay 88k zeny. This room does **not** expire, and as long as you are online and alive, you can stay here and farm items.

There are three types of Crystals in the mining room. They have 50 HP, but the maximum damage is only 1, so you must attack them 50 times to kill them.

There are also Skeleton Workers with **HUUUGE** HP that apply Dispel and Stone Curse. Avoid them—they are useless to try to kill.

The difference between the Crystals is the drop percentage for each item. Without using any drop-rate gear or VIP perks, the drop rates are explained in the table below:

|   | Name        | % drop | ID   |
| - | ----------- | ------ | ---- |
|   | Crystal I   | 15     | 3912 |
|   | Crystal II  | 25     | 3913 |
|   | Crystal III | 50     | 3914 |
