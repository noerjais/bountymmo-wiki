# central laboratory

In this instance, you have a chance to fight 3 random MVPs.

## How to work

{% stepper %}
{% step %}
### Enter Central Lab

Use Warper and go to the **Central Lab** instance.

Talk to the Civilization Explorer to create the instances, then talk with the Temporary Dimension portal.
{% endstep %}

{% step %}
### Enter the portal

Talk to the next NPC and wait 5 seconds. A portal will appear.

Walk right through.
{% endstep %}

{% step %}
### Get the code

Talk to the Senior Researcher. He will give you a number. In the example below, it is **90**.

Solve the code to get in. You need to mix the switches to get the desired number.

The numbers of each switch are:

| 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
| --- | -- | -- | -- | - | - | - | - |

As long as you can get the number, you can go through.

**EXAMPLE ONLY:** 64 + 16 + 8 + 2 = **90** (the number given by the NPC shown in the screenshot)

| **128** | **64** | **32** | **16** | **8** | **4** | **2** | **1** |
| ------- | ------ | ------ | ------ | ----- | ----- | ----- | ----- |
| OFF     | ON     | OFF    | ON     | ON    | OFF   | ON    | OFF   |
| **0**   | **64** | **0**  | **16** | **8** | **0** | **2** | **0** |

**Total:** 64 + 16 + 8 + 2 = **90**

All of the switches are default off, so you just need to select.

In this case, select Switch 2, 4, 5, and 7.
{% endstep %}

{% step %}
### Confirm the code

After that, talk to the Researcher. He will let you in if the code matches. In this case, 90.
{% endstep %}

{% step %}
### Fight the MVPs

Walk right through to the portals and you will reach the Central Lab. Wait around the middle and the MVPs will spawn.

In the example below, I got Dracula, Boitata, and Evil Snake Lord.
{% endstep %}
{% endstepper %}
