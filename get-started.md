# Get Started (new to MMO)

After download the client and launched it (remember to patch it!!). Follow these istruction if you are new into a Ragnarok Private Server:

You must accept Terms and condition

![TermsAndConditions](.gitbook/assets/TermsAndConditions.png)

**Choose the server that is more close to you**

![ChooseServer](.gitbook/assets/ChooseServer.png)

Insert the same credential of the site
where you create the account

![LoginCredential](.gitbook/assets/LoginCredential.png)

Set (and use) a 4 number pin any time you log in

![SecurityCode](.gitbook/assets/SecurityCode.png)

Create a character as you wish clicking on
box with a cross and the word NAME.

The classes is chosen after and you

can change your style also after,

talking with a NPC in mayor cities.

![EmptySpaceCharacter](.gitbook/assets/EmptySpaceCharacter.png)![CreateCharacter](.gitbook/assets/CreateCharacter.png)

After chosen all, press Game Start

![StartGame](.gitbook/assets/StartGame.png)

Once on, you must talk with [Freebies NPC](freebies-npc.md)
that give you some stuff to start this adventure
and help you in leveling character

![Freebies NPC alone](.gitbook/assets/Freebies_NPC_alone.png)
