# Mining Guide

Visit [mining room](mining-room.md) page for more information about it.

In this page we will collect all builds that do a good job to farm crystals.

## Builds

### Sniper - #1

As [indicate](https://discord.com/channels/854582488734892052/859460270505721876/1099878242829213720) <sup>by ***Providence***</sup> this will be a build to farm coins into mining room:

#### Equipment list

- **Headgear High**: Lunar rainbow [1]
    - (optional) nightmare card -> +1 agi
    - (optional) refine Lunar Rainbow to +10 or more, since it will affect the procs and bolt level (ie: +10 Lunar = lvl 10 bolts)
- **Headgear Middle:** sunglasses [1] + nightmare card -> +1 agi
- **Headgear Lower:** Ghostring/Poring Baloon -> No need, just add drop rate and extra soulstrike procs
- **Weapon:** Composite bow [4]  + Pitman, Hill Wind, Laurell Weinder, Red Ferus card
    - (no refine needed on bow, not gonna add the procs %)
- **Armor:** Tights [1] + Ancient Mimic Card (every 18 LUK, +1 Agi) + enchant Agi +2
- **Garment:** any sloted garment [1] + Baphomet Jr Card  (+3 Agi)
- **Shoes:** Sprint shoes [1] (+1 Agi) + Chonchon/Martyr Card (+1 Agi)
- **Accessories:** 2x Bison Horn [1] (+2 Agi) + Kukre Card (+2 Agi)

From these equipments you can get +35 AGI if using lvl 175 Snipers (extra job bonus)

#### Stats:

- **Agi:** 114 - 120
- **Dex:** 100 - 110
- **Luk:** 90 -> give 5 Agi if u use ancient mimic card

Adjust stats to get 193 ASPD with minimum status point investment, AGI and DEX will be major contributor.

The remain points will be useful to:

- STR for extra weight limit
- INT for extra falcon damage (not agains crystal)

#### Shadows equipments:

- Blitz as much as possible
- weapon + armor: 3ASPD
- earring + pedant: 3ASPD
- shield + shoes: 4ASPD (hard to find)
