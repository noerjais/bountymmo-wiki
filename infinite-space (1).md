# infinite space

This instance has 50 floors. Progress by killing the mobs on each floor, similar to Endless Cellar and Endless Tower. The MVPs drop unique cards that are worth hunting.

{% hint style="info" %}
The monsters have a lot of HP, so completing the instance can be time consuming. Choose Normal Mode depending on your gear.
{% endhint %}

## Infinite Space Monsters

### Normal Mode

| **Floor**     | **Monsters**                                   | **MVP**                       |
| ------------- | ---------------------------------------------- | ----------------------------- |
| Floor #1-9    | Regular monsters (e.g., Fabres, Willow)        | None                          |
| **Floor #10** | Regular monsters + MVP area                    | **Infinite Eddga \[MVP]**     |
| Floor #11-19  | Regular monsters (e.g., Wolves, Marin)         | None                          |
| **Floor #20** | Regular monsters + MVP area                    | **Infinite Osiris \[MVP]**    |
| Floor #21-29  | Regular monsters (e.g., Metaller, Deniro)      | None                          |
| **Floor #30** | Regular monsters + MVP area                    | **Infinite Phreeoni \[MVP]**  |
| Floor #31-39  | High-level monsters (e.g., Sandman)            | None                          |
| **Floor #40** | High-level + MVP area                          | **Infinite Orc Hero \[MVP]**  |
| Floor #41-49  | High-level monsters (e.g., High Orc, Megalith) | None                          |
| **Floor #50** | High-level monsters + MVP area                 | **Infinite Tao Gunka \[MVP]** |

### Hard Mode

You can get a chance to randomly encounter:

* Infinite Toad
* Infinite Vagabond Wolf
* Infinite Vocal
* Infinite Eclipse
* Infinite Chimera

The "Infinite" MVP Cards are worth hunting for.

## Examples

* Inifinite Phreeoni Card can add + 100 Crit (weapon slot).
* Infinite Orc Hero Card has 100% chance to stun attackers (headgear slot).
* Infinite Chimera (on hard mode) is a garment card that can MaxHP +8%, MaxSP +4%, but when combined with other can add another 10% ATK & 10% MATK.
* The smaller MVPs (on hard mode), like Infinite Vagabond Wolf (footgear card), can add ATK +10. If refined to +7, ATK +10. If refined to +9, ATK +15.

Happy hunting!
