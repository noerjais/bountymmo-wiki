# socket enchant

Find the NPC Quest Room in Prontera at 147,164, or copy and paste the following into your chat bar:

```
/navi prontera 147/164
```

Inside the room, go to the upper left and find NPC Seiyablem (133,382) and Leablem (137,382).

There are 4 levels for slot enchantment, which determine the success rate for enchantment.

The chances are as follows:

* C: 25%
* B: 20–25%
* A: 10–25%
* S: 5–10%

{% hint style="danger" %}
When you fail to add a slot, the equipment will disappear.
{% endhint %}

{% hint style="warning" %}
Do not carry two identical equipments with you when doing enchantment. Otherwise, a slot may be added to one of the randomly chosen items.
{% endhint %}
