# Wiki Status Templates

This wiki is also an empty box on the admin side. Every feature you have seen on Wikipedia or other Wikis based on the Mediawiki engine isn't in this box.

To use a feature, we must import it one by one on the admin side and know its name; otherwise, it is impossible. At the same time, the official wiki and the game's Discord have very sparse information, and they are not organized in the best way.

Anyway, to help people and admin follow a page's status, I will add some [categories](template-examples.md#categories) to every page to manage and find missing information, missing images, etc.

## Template examples

- ✅ **Done** -  The page is complete and reviewed by Bounty
- 🟡 **Partly done** -  The page is partly complete
- ❌ **Not done** - The page is not done yet
- 💬 **Comment** -  To add a simple comment for next review
- ⏸️ **On hold** - No other informations available but we need them
- 🚧 **Working** -  There are information that must be transcribed on the page
- 💡 **Idea** - There are some idea to do a better version with other informations or style
- 🔎 **Reviewing** - The page must be reviewed by Bounty
- 📝 **Note** -  Add some notes
- 🔴 **High priority** - High priority
- ❓ **Question** -  Indicate that there are one or more questions

## Categories

Categories defined and used in pages:
```text
[[Category:Information missing]]
[[Category:Image missing]]
[[Category:Formatting]]
[[Category:To verify]]
[[Category:On hold]]
[[Category:Reviewing]]
[[Category:Link missing]]
```
