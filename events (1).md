# events

Here you can find information about all events on this server.

## Devil Square Event

Click the NPC at Prontera (156,149) when it announces that Devil Square is about to start.

**Activation time:** At 00:00 and every 2 hours.

**Reward:** x1 [Devil Square Token](currency-list/#devil-square-token) - x10 [Poring Coin](currency-list/#poring-coin)

## Mushroom Event

In the public chat you can read the announcement that warns you where the mushrooms have spawned. They could be at Izlude or Geffen. Check NPC at Prontera (167,139) to see if any ongoing event is active.

**Activation time:** If all mushrooms have been killed, at 00:00 and every hour.

**Reward for every mushroom found:** x1 [Mushroom Finder Token](currency-list/#mushroom-finder-token) - x1 [Bounty **Coin**](currency-list/#bounty-coin)

## Mr. Dice Event

When it is active, there is a teleport in Prontera Town **(insert coordinate here)** that teleports you into a special room. When the game starts, as the narrator says, you must choose a box from 1 to 4 where to stay. A number is thrown and if it matches the box you are in, you win. The numbers are drawn on the ground with tiles. In case there are more players in different boxes, if you lose, you are instantly teleported to Prontera Town. The game finishes when only one player remains.

**Activation time:**

**Reward:** x1 [Dice Beater Token](currency-list/#dice-beater-token) - x10 [Poring Coin](currency-list/#poring-coin)

**Reward for every monster killed:** x3 [Poring Coin](currency-list/#poring-coin)
